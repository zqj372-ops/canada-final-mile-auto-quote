# 加拿大尾程派送报价模板

默认使用正式模板。只有用户明确要求“企微短格式”“群里短回复”“短一点”时，才使用企微短模板。

## 正式模板

```text
地址：[完整地址]
地址类型：[商业地址/私人住宅地址/农村住宅地址]（[判断依据，可省略]）
货物：[品名/包装] / [体积] CBM / [重量] KG / [尺寸或件数，可省略]
报价：$[金额] USD [多伦多/卡尔加里]派送（Zone [数字]）

服务条款：
- 送货到门口路边，不含其他任何操作
- [商业地址（不含住宅附加费）/私人地址（含住宅附加费 +50USD/票）]

尾板费用：
- 收货方无卸货平台需司机卸货至地面：+$50/票
- 尾板承重500KG/板，>500KG及超长货物由收货人自卸
- 需司机手叉车配合：另+$50USD
- 免费等待30分钟，超过按$35USD/半小时计（不满半小时按半小时算）

- 价格为预估，最终以供应商实测地址及卡车准入情况为准
- 如下单后需填写对应单号引用此报价
```

### 正式模板规则

- 地址行保留客户提供的完整地址。
- 地址类型行必须写商业/私人住宅/农村住宅；有可靠证据时放入括号。
- 货物行优先写品名、包装、CBM、KG、尺寸；缺失项不要编。
- 报价行使用 `$[金额] USD [始发仓]派送（Zone [zone]）`。
- 商业地址服务条款写：`商业地址（不含住宅附加费）`。
- 住宅/私人地址服务条款写：`私人地址（含住宅附加费 +50USD/票）`。
- 不在正式模板里展开内部查找过程；异常回退只在必要时用一句话说明锚点。

## 企微短模板

```text
@报价请@我，助理：周谨
[完整邮编] / [City Province]，[商业地址/私人住宅地址]，[CBM]CBM / [KG]KG    [多伦多/卡尔加里]派送
报价：[金额]USD
备注：
- [私人/住宅地址 +50USD/票，仅住宅时加这一行]
- 送货到门口路边，不含其他操作
- 无卸货平台需尾板 +50USD/票
- 需手叉车配合 +50USD/票
- 免费等待30分钟，超时35USD/半小时
- 价格以供应商实测地址及卡车准入情况为准
```

### 企微短模板规则

- 不输出 Zone、托数、回退锚点、计算过程。
- 金额不带 `$`，整数不要小数位。
- 住宅/私人地址时，报价金额已包含住宅费，并在备注第一行写明。
