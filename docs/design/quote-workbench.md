# 报价工作台实现基准

本次重构保留 React/Vite、现有认证、后台配置、价格矩阵、人工任务和销售记录。
采用仓库已有确认工作台设计的双接口方向；新增解析快路径和真实耗时。

## 视觉基准

参考图：`quote-workbench-concept.png`，1536 × 1024，由内置 Image Gen 生成。
生成简报：加拿大尾程销售工作台，白色顶栏，报价工作台/报价记录导航，客户原文、
可编辑字段、报价结果三栏；不添加后台菜单、统计数字或示例金额。

- 背景 `#f5f7fa`；面板纯白；正文 `#182b39`；次要文字 `#667b91`。
- 主色 `#087f75`；边框 `#dce4eb`；圆角 10px；面板内边距 22px。
- 系统无衬线字体；主标题 28px，面板标题 20px，正文/控件 14px。
- 顶栏 64px；页面最大宽度 1600px，桌面边距 32px，三栏间距 16px。
- 组件：顶部导航、三步进度、原文输入、字段表单、明细折叠、报价/风险区。
- 图标使用原生 SVG 细线文档图标；无图片背景、渐变、装饰品牌资产。
- 首屏文案：加拿大尾程报价；粘贴客户询价，核对货物与地址，再生成报价。
  客户询价；填入示例；解析字段；清空；导入文本；核对信息；确认并计算报价；
  报价结果；等待报价。字段和附加服务选项继续读取后台配置。
- 响应式：窄屏依照输入、核对、结果堆叠，所有控件保持可访问。

与概念图的必要差异：展示实际账号；结果状态和错误提示来自 API；表单增补
显式托数、最长边、可堆叠和等待时间；示例文本使用后台配置；不把设计示例当成价格。

## 交付边界

解析不创建报价/人工任务，也不发送通知；确认报价原子保存审计、记录和必要的人工任务。
明确的标签式单票输入可本地解析，其他内容继续使用已有双模型并行解析与确定性校验。
不修改既有生产价格，不迁移数据库，不提交、推送或部署。
