# AI报价系统 一页速查卡

## 一句话记住

价格是系统按价格表算的，AI 只认字、填表、写话术。**待人工复核的单，坚决不发客户。**

## 销售：加拿大尾程（散货卡派）

1. 粘贴客户询价原文；
2. 核对包装类型、地址类型、附加服务（拿不准用默认）；
3. 点“开始智能报价”；
4. 核对件数、体积、重量、地址、邮编；
5. 看结果：
   - 报价已完成 → 复制客户回复 / 导出报价；
   - 报价待人工复核 → 别发，交运营。

乡村邮编（前3位第2位是0）会弹二次确认：卡车能不能进、要不要尾板/叉车、偏远附加费确认过没。

## 销售：AI 整柜（整柜海运）

1. 按表填必填项：客户、联系人、起运港、目的港、交付范围、品名、件数、毛重、体积、柜型柜量、特殊属性、出货日期、是否有进口商、确认申报；
2. 点“预检货物重算”，看冲突和缺失；
3. 点“提交整柜报价”；
4. 完成后：复制客户回复 / 打印 A4 或另存 PDF；
5. 待人工复核 → 等运营，别发。

要点：危险品/带电要 SDS/UN 资料；木包装要 IPPC；到门要完整地址、邮编、地址类型、预约/尾板/叉车。

## 运营：每天先做人工任务

处理工作台 → 人工任务 → 点开一单 → 看明细 → 填：

- 状态（待处理/处理中/已解决/已取消）；
- 处理人；
- 人工确认金额 USD；
- 处理备注（一定写，以后查得到）；
- 可选：保存后邮件发送给客户。

然后点“保存处理结果”。确认金额只对这一单有效，**不会改价格表**。

其他页签：

- 诊断队列：只看不动，Hermes 只给建议；
- 批量报告：先处理“价格矩阵缺口”；
- Hermes 学习：人工批准后才会复用；
- 审计查询：按报价 ID 查一单怎么算的。

## 管理员：维护

- 价格矩阵：改燃油/附加费、单仓 Zone 开关、每托价格；新增价格必填来源备注；表格导入先校验再确认；
- 城市配置：搜城市或 FSA → 管理邮编 → 批量保存（错一条整批回滚）；
- 报价规则：可视化表单改，别动高级 JSON；
- 整柜设置：改草稿 → 校验 → 发布；
- 系统配置：AI 模型、搜索、邮件、账号，出了问题先找管理员。

## 四条红线

1. 待复核不报价；
2. 不估价格；
3. 不瞎填区域；
4. 资料不全不报价。

客户资料、价格、账号密码不外传。不知道能不能点，先问主管。
