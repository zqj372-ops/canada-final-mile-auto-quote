# AI报价前端系统 培训资料

> 给新人看的，会用电脑、会复制粘贴就能上手。

---

## 一、这个系统是做什么的

一句话：**帮我们根据客户的货物和收货地址，快速算出加拿大派送（尾程）或整柜海运的报价，并生成可以发给客户的报价话术。**

平时的工作就是一条流水线：

1. 客户从微信、邮件发来询价；
2. 我们把信息填进系统；
3. 系统算出价格；
4. 我们把报价发给客户；
5. 系统留底，以后查得到。

**最重要的一个道理：价格不是 AI 乱编的。** AI 只负责“认字、填表、写话术”，价格是系统按后台的价格表一步步算出来的。所以后台价格表必须准确，我们填的信息也必须准确，价格才算得准。

---

## 二、谁能进系统、干什么

| 身份 | 能进哪里 | 平时干什么 |
| --- | --- | --- |
| 销售 | 销售前台 | 报价、看报价记录、把报价发给客户 |
| 运营 | 后台 | 处理系统算不出来的单（人工任务）、看诊断、审学习候选、查审计 |
| 管理员 | 后台 | 运营能做的一切，还能改价格、城市、账号、AI模型、邮件等配置 |
| 查看者 | 后台 | 只能看，不能改 |

注意事项：

- 账号密码不要告诉别人，也不要借给别人用。
- 销售账号进不了后台；后台账号一般也不用来做前台报价。
- 页面右上角能看到自己是谁、什么身份，注意别登错账号。

## 三、怎么登录

系统有两个入口：

1. **销售前台**：打开销售前台地址，输入销售账号和密码。
2. **后台**：打开后台地址，输入管理员、运营或查看者账号和密码。

登录失败时，先看提示是不是账号或密码错了；太久没操作会提示“登录已失效”，重新登录就行。

用完要退出：点右上角的账号 → 退出登录。**不要直接关浏览器就当退出了，共用电脑时一定要退出。**

## 四、销售前台怎么用（重点）

### 4.1 页面长什么样

- 顶部左边：**AI 报价**、**报价记录**两个标签，来回切换。
- 顶部右上角：搜索框（搜报价记录用的）和账号菜单。
- 页面中间：两个报价模式按钮——**加拿大尾程**、**AI 整柜**。
- 状态栏：显示当前这票是“报价已完成”还是“需人工复核”。

### 4.2 加拿大尾程（散货、卡车派送报价）

尾程的特点是：**可以整段粘贴客户的话**，系统自动认字段。操作步骤：

1. 确认模式是“加拿大尾程”。
2. 把客户询价的原文（微信、邮件里那段话）**整个复制，粘贴到输入框**。
3. 看一下右侧的包装类型、地址类型、附加服务、等待时间，拿不准就先用默认值。
4. 点**“开始智能报价”**。
5. 系统会先“读”出货物、地址、服务这些信息，在**解析结果**里展示。
6. 认真核对这几项：
   - 件数、总体积、总重量对不对；
   - 收货地址、城市、省份、邮编对不对；
   - 有没有标“缺失字段”，缺了什么。
7. 点**“报价结果”**看结果：
   - 显示“报价已完成”：有金额，可以点**“复制客户回复”**发给客户，也可以点**“导出报价”**存成文本文件；
   - 显示“报价待人工复核”：**不要发给客户**，交给运营处理（见第五章）。

特别提醒（乡村邮编）：

- 邮编前3位如果第2位是 0，就属于乡村区域，系统会弹“乡村邮编二次确认”。
- 这时要逐项核对：卡车能不能进、现场有没有装卸条件、要不要尾板/手叉车/预约、偏远附加费确认过没有。
- 点“我已核对”只是表示你核对了，价格最终还要以供应商实测地址为准。

### 4.3 AI 整柜（整柜海运报价）

整柜和尾程不一样：**不能粘贴一大段话**，必须按表格一项一项填。这是为了每一票都准确、有底。

必填项有这些（带 * 的）：

- 客户/公司名称
- 联系人及联系方式
- 客户类型/业务角色
- 起运城市/港口（POL）
- 目的城市/港口（POD）
- 交付范围
- 中文/英文品名
- 件数
- 总毛重 KG
- 总体积 CBM
- 柜型柜量
- 特殊属性（至少选一项）
- 预计出货/备货日期
- 是否有加拿大进口商
- 勾选“已确认如实申报”

填表技巧：

- **柜型柜量**：点“+ 增加柜型”，填 20GP / 40GP / 40HQ 和数量。
- **货物分项**：可填可不填。填了之后，系统会按“长 × 宽 × 高 × 数量”重新算总量；如果你填的总量和分项算出来的对不上，系统会标“冲突”，以算出来的为准。
- **特殊属性**：勾了“危险品”或“带电”，必须填 SDS / UN 编号或电池资料；勾了“木包装”，要选 IPPC 情况。
- **到门（door delivery）**：目的邮编、完整收货地址、地址类型、预约、尾板、叉车这些都要填清楚。
- **进口**：选了“没有加拿大进口商”，必须选是否包税。
- **货值与申报**：进口/包税时货值必填，HS 编码清关前必须确认。

操作步骤：

1. 填完表单，先点**“预检货物重算”**，看有没有冲突或缺失。
2. 再点**“提交整柜报价”**。
3. 结果页看费用明细（项目、数量、单价、金额）和合计。
4. 点**“复制客户回复”**发给客户，或点**“打印 A4 报价单 / 另存为 PDF”**。
5. 如果显示“报价待人工复核”，等运营确认，**不要直接发**。

### 4.4 报价记录

- 点顶部**“报价记录”**，能看到自己报过的所有单。
- 用顶部搜索框搜报价 ID、地址、原始询价。
- 可以筛选：全部 / 已报价 / 待人工复核。
- 点开一单，能看到明细、风险、客户回复，需要时可以重新复制。
- 想报新单，点**“新建报价”**。

## 五、后台：运营每天做什么

### 5.1 运营控制台（首页）

打开后台看到的第一屏，是**近24小时运营概览**：

- 报价总数、报价成功数、成功率；
- 需人工处理数；
- Hermes 待审数；
- AI 问题（需处理）数。

下面还有**待处理队列**（人工报价任务、Hermes 学习候选、AI 问题记录）、**最近报价**和**风险标签分布**。

工作原则：**先看黄色、红色的数字，先处理“需人工处理”的。**

### 5.2 处理工作台

这是运营的主战场，顶部有 5 个页签：

#### ① 人工任务（每天必看）

系统算不出来的单、缺信息的单、高风险的单，都会进这里。

操作步骤：

1. 看左侧列表：报价 ID、目的地、原因、风险标签。
2. 点开一单，先看**询价明细**：货物信息、地址信息、报价/服务信息、缺失字段。
3. 在**处理表单**里填：
   - 状态：待处理 / 处理中 / 已解决 / 已取消；
   - 处理人：谁处理的写谁；
   - 人工确认金额 USD：最终确认的金额；
   - 处理备注：处理过程、确认重点、特殊情况（一定要写，以后查得到）。
4. 如果客户要收到邮件，勾上“保存后邮件发送给客户”，选好邮件配置。
5. 点**“保存处理结果”**。填“已解决”保存时，系统会二次确认。

**必须记住**：人工确认金额只对**这一单**有效，不会改动价格表；要改价格，走第六章的“价格矩阵”。

#### ② 诊断队列

系统给每一票报价做的“体检报告”，**只看、不动**。里面有：

- 系统报价逻辑（来源类型、命中方式、命中的始发仓和 Zone、基础价）；
- 价格矩阵检查（有没有找到对应价格）；
- 相邻 FSA 证据（附近区域的情况，只作参考）；
- Hermes 建议（建议动作、建议 Zone、置信度）。

记住：**Hermes 只给建议，不能自动改价。**

#### ③ 批量报告

系统随机抽查一批邮编做“命中测试”，看哪些地方报得出价、哪些报不出。重点看：

- 价格矩阵缺口（最值得先处理）；
- 人工复核聚类（哪些问题反复出现）；
- 模糊命中聚类。

#### ④ Hermes 学习

人工确认过的单，系统想“学”成一个以后能复用的规则。在这里审核：

- 觉得合理，批准发布；
- 觉得不行，退回。

**没批准之前，系统不会自己用。** 这是最重要的一道闸。

#### ⑤ 审计查询

输入报价 ID（15 位短号），查这一单**是怎么算出来的**：

- 价格来源、命中的线路/分区；
- 基础派送费、报价合计；
- 风险标签；
- 请求原文和报价结果（原始数据，给技术人员看的）。

客户投诉、对账、查价的时候，都用这里。

## 六、后台：管理员维护（一般只有管理员动）

### 6.1 价格矩阵（价格表）

位置：左侧菜单 → **价格与报价配置 → 价格矩阵**。

三个主要区域：

**① 燃油和附加费**

- 默认燃油附加比例（%）；
- 住宅附加费；
- 尾板费；
- 手叉车费；
- 预约费；
- 等待费（超过免费等待后按半小时算）。

改完点保存。

**② 新增 / 覆盖 Zone 价格**

填：始发仓、Zone（区域编号）、托数、基础派送费（USD）、来源备注。

**来源备注一定要写**，比如“6月供应商表 XX”，以后才知道这个价是哪来的。

**③ 价格矩阵与分区状态**

- 可以按始发仓、Zone、托数筛选；
- 可以单独**开/关**某个“始发仓 + Zone”的自动报价（关闭只是暂停自动报价，价格不会丢）；
- 可以直接改每一托的价格，改完点保存；
- 点**“表格导入”**可以批量导入 CSV / XLSX / XLS 表格：先选文件 → 系统校验 → 看预览 → 确认后才写入，完成后会告诉你新增多少条、覆盖多少条。

**改价前先问清楚**：来源是什么、什么时候生效、谁批准的。不要为了让一单“能报出价”就乱加价格。

### 6.2 城市配置（城市 / 邮编 / 区域）

位置：**价格与报价配置 → 城市配置**。

- 先**搜索城市或 FSA**（FSA 就是邮编前 3 位，比如 V6V），再点开管理；
- 一个城市可以加多个邮编前缀，每个邮编指定标准城市名和 Zone；
- 全部改完点**“批量保存”**；只要有一条有问题，整批都不会生效（不会改一半）；
- 新增城市时，一次可以加多个 FSA。

原则：**城市、邮编、Zone 一致才报得出价**；查不到就留给人工，不要硬套一个区域。

### 6.3 报价规则（前台配置）

位置：**价格与报价配置 → 报价规则**。

这里控制前台长什么样、怎么识别：

- 基础文案：页面标题、按钮文字、示例输入；
- 识别与默认值：包装类型、地址类型、附加服务选项、默认值；
- 分区价格：总开关、默认自动报价最高 Zone、燃油比例、各种附加费；
- 风险与标签：重货/泡货密度阈值、超长边阈值、风险标签中文名；
- 报价话术：报价有效期、费用包含、费用不含、报价备注；
- 高级 JSON：排障用的，**日常不要动**。

改完点“保存配置”，前台下次刷新就生效。

### 6.4 整柜报价设置

位置：**价格与报价配置 → 整柜报价设置**。

- **费率卡**：一个“起运港 + 目的港 + 柜型”的费率表，可以加费用行（运费、附加费等），设置优先级、启用/停用；
- **配置草稿**：必填字段、汇率、费用行、定价方式（自动 / 按实际 / 人工 / 需报价）、显示方式。

流程：**改草稿 → 校验 → 发布**。没发布前不影响前台报价。

### 6.5 其他系统配置

以下一般只有管理员动，出了问题先找管理员，不要自己乱试：

- **AI 模型配置**：填模型接口和密钥，可以自动拉模型列表；给 Hermes（学习助手）单独切换模型。
- **搜索 API 配置**：填搜索密钥，用来查地址和行情参考，可以点“测试”看通不通。
- **邮件通知配置**：填发件邮箱（SMTP），可以“测试发送”；注明用途（人工任务 / 报价通知），设一个默认邮箱。
- **用户账号**：新增账号（登录账号、显示名称、初始密码、角色），改密码、启用/停用。

## 七、几条红线（一定要记住）

1. 系统显示“待人工复核”的报价，**坚决不能发给客户**。
2. 价格只能来自系统计算结果，**不能自己估一个数**写在报价里。
3. 城市、邮编、Zone 查不到，按人工处理，**不能瞎填一个区域**。
4. 危险品、带电、木包装资料不全，**不能自动报价**。
5. 人工确认金额**不会改价格表**；要改价格走价格矩阵。
6. Hermes 的建议只是建议，**人工批准后才生效**。
7. 客户地址、价格、账号密码都是公司资料，**不能外传**。
8. 不知道按钮能不能点，**先问主管，别乱试**。

## 八、常见问题

**问：提示“缺少 XX 字段”怎么办？**
答：把缺的补上再算一遍；补不了的，按人工处理。

**问：显示“需要人工确认”，但客户很急怎么办？**
答：告诉客户稍等，联系运营加急处理；自己不要报数。

**问：邮编显示找不到怎么办？**
答：先确认没抄错，再看城市、省份对不对；还是查不到，走人工。

**问：复制了客户回复，发之前要不要检查？**
答：要。核对金额、报价有效期、费用包含/不含、地址对不对，再发。

**问：改了价格表，前台为什么没变？**
答：价格保存后，**新报价**会按新价格算；已经算好的旧单不变。

**问：不小心退出登录 / 白屏了怎么办？**
答：刷新页面，重新登录；还不行，找管理员。

**问：看到“JSON”“API”“FSA”这些词害怕怎么办？**
答：不用怕，日常操作不需要懂。FSA 就是邮编前 3 位，JSON 是系统内部的数据格式，一般不用动。

## 九、练习（培训时做）

1. 用一份模拟询价（含地址、邮编、货物尺寸重量），走一遍“加拿大尾程”完整流程，说出哪一步会进入人工。
2. 用同一份询价，故意把邮编少写一位，看系统怎么提示，说明为什么不能直接发给客户。
3. 模拟一票整柜：填必填项，把“危险品”勾上但不填 SDS 资料，看系统反应。
4. 在人工任务里，给一单填“处理人、确认金额、备注”，说明为什么备注必须写。
5. 口述三条红线，并说明违反会有什么后果。

## 附：一页速查卡

**销售报价**

1. 尾程：粘贴客户原话 → 核对默认值 → 开始智能报价 → 核对解析结果 → 看报价结果 → 已完成就“复制/导出”，待复核就交运营。
2. 整柜：按表填必填项 → 预检货物重算 → 提交整柜报价 → 复制客户回复 / 打印 PDF。

**运营处理**

工作台 → 人工任务 → 看询价明细 → 填处理人、确认金额、备注 → 保存。

**管理员维护**

- 改价格：价格矩阵 → 改完保存，来源备注必填。
- 城市/邮编：城市配置 → 批量保存，错一条整批回滚。
- 整柜设置：改草稿 → 校验 → 发布。

**四条红线**

- 待复核不报价；
- 不估价格；
- 不瞎填区域；
- 资料不全不报价。
