# 报价工作台重构交付

日期：2026-10-12。首轮基于 `e7d26d9`，已通过 PR #7 合并并发布为 `63775ed4`。

## 实现

1. 销售页面采用原文、确认字段、报价结果三栏。状态区分缺失字段、请求失败、人工复核、
   已报价和修改后待重算；保留原文，字段旁显示来源，尺寸原文可展开检查。
2. 新增保守的本地解析路径：单票、完整标签、明确单位、无重复/冲突才跳过模型。
   支持公英制换算，分清总重与单件重。混合包装、对话、更正或含糊文本继续交给
   原有并行货物/地址模型解析；没有更换模型，也没有把所有输入强行送进规则解析。
3. 确认报价直接使用编辑后的结构化字段，不再次调用模型。成功的价格矩阵结果保持
   权威；只有需要人工的结果才尝试已有审核学习规则，仍受始发仓及价格开关约束。
4. 审计、销售记录、人工任务、替代操作和诊断快照同事务保存。保存失败不会返回可发送价格。
   诊断参考上下文在提交后由后台补齐；上下文准备失败不影响已保存报价。
5. 原文修改清空草稿及报价；计价字段修改保留旧结果供对照，但禁用复制和导出。
   乡村邮编发价前仍需二次确认。重新报价可取消原待处理人工任务并保留替代记录。
6. 修正原有客户回复错误：选择尾板后不再写“不带尾板”；已含服务按实际费用列出，
   未选尾板、手叉车及等待费说明读取当前后端收费配置。

没有修改生产价格数据。发布时核对恢复线上已有的 M2M `0024` 迁移，新增
`0025_learning_candidate_idempotency` 部分唯一索引，保护新版学习候选去重，
没有增加工作台业务表。旧 `ai-auto-quote`、`zone-calculate` 及后台页面保留，学习价格优先级已统一。
新流程不自动发送邮件/企业微信，后台人工处理入口保留。
新版结果使用后端确定性销售回复；旧工作台 `copy_template` 配置仍保留给旧组件，
不会把 USD 金额仅因显示配置而标成其他币种。新的两步流程文案不再使用旧的一键报价按钮文案。

## 接口约定

| 接口 | 核心输入 | 核心输出 / 行为 |
| --- | --- | --- |
| `/quotes/ai-extract` | `customer_message`，可选 `force_ai` | 草稿、来源、缺失/校验信息、本地地址校验、模式和耗时；零报价业务写入 |
| `/quotes/confirmed-calculate` | `quote`、原文、来源，可选解析快照和待替代报价 ID | 报价结果、真实记录/任务 ID、替代 ID、诊断入队状态 |

`field_provenance` 的键仅限报价输入字段，值为 `customer_original`、`ai_extracted`、
`deterministic_extracted` 或 `human_edited`；false 和 0 也必须记录来源。
尾板、手叉车和预约未提及时，草稿保留 null，销售确认后才能报价。客户补充不能作为解析错误标签。
来源记录用于追溯，不能代替人工对客户原文的核实。

省份/邮编冲突、无效邮编、空城市、软包装缺堆叠条件等会阻止确认报价。
不可替代不存在、非本人、已处理或已替代的人工单；此类请求返回 409。
解析失败不生成“人工复核单”。确认报价网络响应丢失时，应先查询报价记录再重试；
本次未增加跨请求幂等键。

## 件毛体与计算结果展示

- 解析完成后直接显示件数、总毛重 kg、总体积 CBM；逐项显示数量、统一后的尺寸、
